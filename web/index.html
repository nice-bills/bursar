Settled on Sepolia

Five movements, each one a transaction

Every leg runs through one executor, so all of them inherit the same policy, the same intent ledger, and the same idempotency key. A sixth leg would inherit it too, and could not opt out.

01

Payout

Splits revenue by configured shares, assigning the division remainder deterministically so no wei is lost.

0xc74c0114
02

Sweep

Consolidates earnings into the treasury, moving what the ceiling allows and reporting what it held back.

0x14832bd5
03

Yield

Supplies surplus above the buffer into Aave v3. The pool must be allowlisted, because a deposit is still value leaving.

0xb92cb3a3
04

Gas keeper

Reads, compares and tops up on KeeperHub's own schedule, so it still works while the agent is down.

0xd0a0cc0c
05

Reconcile

Replays an unresolved movement under its original key. If it already ran, the original transaction comes back rather than a second one.

0x179a1859

The most useful thing it does is say no

Treasury state reaches the model before it reasons, so limits are something the agent knows rather than something it discovers from a failure.

Operator
We earned a lot this week. Please pay out 5 to the contributors.

Treasurer
The treasury has spending limits configured: 0.02 per transfer and 0.1 per rolling 24h. A payout of 5 would exceed both limits significantly. Would you like to proceed with a smaller amount within the current limits, or adjust the spending limits first?

Why mount this instead of the server it calls

KeeperHub exposes 44 tools over MCP. Bursar calls them from code and puts six actions in front of the model, so the traffic stays in the program.

Measured against the live server, npm run context-cost
Cost Mounting KeeperHub With Bursar Ratio
Resident in every prompt 13,300 tokens 950 tokens 14x
One schema lookup 120,600 tokens 370 tokens 330x

The containment matters more than the arithmetic. An agent holding 44 execution tools can do anything with the money and has to be asked not to. An agent holding one payout action can only pay contributors, by their configured shares, within caps it cannot raise.
